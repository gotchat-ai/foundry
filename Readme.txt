== Description ==
This package contains the main GotChat framework release.

== Installation ==
1. Make sure you have python installed on your computer(PC, Linux, or Mac)
2. Download the files and put it in a folder (this is where this app will run)
3. Windows: right click on start_setup_wizard.ps1 and select "Run With Powershell"
4. Linux and Mac: go to app directory and run "bash start_setup_wizard.sh" in your terminal
5. Go through the instruction to setup the required environment to run this chat platform
6. Select GPU if you don't know then select "I don't know" 
7. On first run, it will generate an admin password, write it down or change it there
8. Go through the in-chat setup wizard for the first time user running it (this will setup your local model and configurations)
